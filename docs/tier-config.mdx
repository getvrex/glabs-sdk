# Tier Configuration

The SDK provides utility functions for working with Pro and Ultra account tiers. These are used internally but exported for advanced use cases.

## Tier Capabilities

```typescript
import { getTierCapabilities } from '@getvrex/glabs-sdk';

const capabilities = getTierCapabilities('pro');
// {
//   supportedVideoModes: ['quality', 'fast'],
//   defaultVideoMode: 'fast',
//   paygateTier: 'PAYGATE_TIER_ONE',
//   supportsUpsample: true,
//   supportsQualityMode: true,
//   maxImageGenerationCount: 4,
// }

const ultraCaps = getTierCapabilities('ultra');
// {
//   supportedVideoModes: ['quality', 'fast'],
//   defaultVideoMode: 'quality',
//   paygateTier: 'PAYGATE_TIER_TWO',
//   supportsUpsample: true,
//   supportsQualityMode: true,
//   maxImageGenerationCount: 4,
// }
```

## Video API Config

Get complete API configuration for a video generation request:

```typescript
import { getVideoApiConfig } from '@getvrex/glabs-sdk';

const config = getVideoApiConfig('text-to-video', 'pro', '16:9', 'fast');
// {
//   videoModelKey: 'veo_3_1_t2v_fast',
//   userPaygateTier: 'PAYGATE_TIER_ONE',
//   effectiveVideoMode: 'fast',
//   aspectRatioEnum: 'VIDEO_ASPECT_RATIO_LANDSCAPE',
// }
```

### Video Generation Types

```typescript
type VideoGenerationType =
  | 'text-to-video'
  | 'image-to-video'
  | 'image-to-video-fl'
  | 'extend'
  | 'reshoot'
  | 'upsample'
  | 'reference-images';
```

## Video Model Key

Get the internal model key for a specific generation type:

```typescript
import { getVideoModelKey } from '@getvrex/glabs-sdk';

getVideoModelKey('text-to-video', 'pro', '16:9', 'fast');
// 'veo_3_1_t2v_fast'

getVideoModelKey('text-to-video', 'ultra', '16:9', 'fast');
// 'veo_3_1_t2v_fast_ultra'

getVideoModelKey('text-to-video', 'pro', '9:16', 'quality');
// 'veo_3_1_t2v_portrait'

getVideoModelKey('reshoot', 'pro', '16:9');
// 'veo_3_0_reshoot_landscape'

getVideoModelKey('upsample', 'pro', '16:9');
// 'veo_3_1_upsampler_4k'
```

### Model Naming Pattern

| Tier | Mode | Model Suffix |
|------|------|-------------|
| Pro | fast | `_fast` |
| Pro | quality | (base) |
| Ultra | fast | `_fast_ultra` |
| Ultra | quality | (base, same as Pro) |

Portrait aspect ratios add `_portrait`. Square uses the landscape model.

## Effective Video Mode

Get the actual mode after applying tier restrictions:

```typescript
import { getEffectiveVideoMode } from '@getvrex/glabs-sdk';

getEffectiveVideoMode('pro');          // 'fast' (default for pro)
getEffectiveVideoMode('ultra');        // 'quality' (default for ultra)
getEffectiveVideoMode('pro', 'quality'); // 'quality'
getEffectiveVideoMode('ultra', 'fast');  // 'fast'
```

## Image API Config

```typescript
import { getImageApiConfig } from '@getvrex/glabs-sdk';

getImageApiConfig('pro', '16:9');
// { imageModelName: 'GEM_PIX', aspectRatioEnum: 'IMAGE_ASPECT_RATIO_LANDSCAPE' }

getImageApiConfig('pro', '16:9', 'nanobananapro');
// { imageModelName: 'GEM_PIX_2', aspectRatioEnum: 'IMAGE_ASPECT_RATIO_LANDSCAPE' }
```

## Feature Support Check

Check if a feature is supported for a tier:

```typescript
import { isFeatureSupported } from '@getvrex/glabs-sdk';

isFeatureSupported('upsample', 'pro');
// { supported: true }

isFeatureSupported('upsample', 'pro', '9:16');
// { supported: false, reason: 'HD upscaling only supports 16:9 landscape videos' }

isFeatureSupported('quality_mode', 'pro');
// { supported: true }

isFeatureSupported('extend', 'pro');
// { supported: true }
```

### Supported Features

```typescript
type SupportedFeature =
  | 'upsample'
  | 'quality_mode'
  | 'extend'
  | 'reshoot'
  | 'reference_images';
```

## Aspect Ratio Enums

```typescript
import { getVideoAspectRatioEnum, getImageAspectRatioEnum } from '@getvrex/glabs-sdk';

getVideoAspectRatioEnum('16:9'); // 'VIDEO_ASPECT_RATIO_LANDSCAPE'
getVideoAspectRatioEnum('9:16'); // 'VIDEO_ASPECT_RATIO_PORTRAIT'
getVideoAspectRatioEnum('1:1');  // 'VIDEO_ASPECT_RATIO_SQUARE'

getImageAspectRatioEnum('16:9'); // 'IMAGE_ASPECT_RATIO_LANDSCAPE'
getImageAspectRatioEnum('9:16'); // 'IMAGE_ASPECT_RATIO_PORTRAIT'
getImageAspectRatioEnum('1:1');  // 'IMAGE_ASPECT_RATIO_SQUARE'
```

## PaygateTier

```typescript
import { getPaygateTier } from '@getvrex/glabs-sdk';

getPaygateTier('pro');   // 'PAYGATE_TIER_ONE'
getPaygateTier('ultra'); // 'PAYGATE_TIER_TWO'
```

## All Exported Functions

| Function | Description |
|----------|-------------|
| `getTierCapabilities(tier)` | Get tier capabilities object |
| `getEffectiveVideoMode(tier, mode?)` | Get effective video mode |
| `getPaygateTier(tier)` | Get PaygateTier enum value |
| `getVideoAspectRatioEnum(ratio)` | Convert aspect ratio to video enum |
| `getImageAspectRatioEnum(ratio)` | Convert aspect ratio to image enum |
| `getVideoModelKey(type, tier, ratio, mode?)` | Get video model key |
| `getVideoApiConfig(type, tier, ratio, mode?)` | Get full video API config |
| `getImageApiConfig(tier, ratio, model?)` | Get full image API config |
| `isFeatureSupported(feature, tier, ratio?)` | Check feature support |
