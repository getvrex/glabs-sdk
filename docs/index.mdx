# GLabs SDK

`@getvrex/glabs-sdk` is a TypeScript SDK for Google Labs AI media generation APIs — **Imagen 4** for images and **Veo 3** for videos.

## Features

- **Image Generation** — Imagen 4 with multiple aspect ratios, batch generation, upsampling to 2K/4K
- **Video Generation** — Veo 3 text-to-video, image-to-video, first+last frame, extend, camera control reshoot, reference images, HD/4K upsample
- **Project Management** — List, get, and auto-resolve Google Labs projects
- **Auto Token Refresh** — Automatic ST→AT (session token to access token) refresh with proactive renewal
- **reCAPTCHA Integration** — 7 providers: Regotcha, CapSolver, YesCaptcha, Veo3Solver, Playwright browser, Chrome browser, Custom
- **OpenAI-Compatible Server** — Drop-in `/v1/chat/completions` and `/v1/models` endpoints
- **Whisk Service** — Standalone Imagen 3.5 generation via Google Whisk API
- **Tier-Aware** — Automatic model selection based on Pro/Ultra account tier
- **Polling** — Built-in `pollOperation()` for video generation with progress callbacks
- **Type-Safe** — Full TypeScript support with 60+ exported types

## Quick Start

```typescript
import { GLabsClient } from '@getvrex/glabs-sdk';

const client = new GLabsClient({
  bearerToken: 'your-bearer-token',
  sessionToken: 'your-session-token',  // enables auto token refresh
  accountTier: 'pro',
  recaptcha: {
    provider: 'regotcha',
    apiKey: 'your-api-key',
  },
});

// Generate an image
const imageResult = await client.images.generate({
  prompt: 'A beautiful sunset over mountains',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});

// Generate a video and poll until done
const operation = await client.videos.generateTextToVideo({
  prompt: 'A cinematic drone shot of a city',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});

const result = await client.videos.pollOperation({
  operationName: operation.operationName,
  onProgress: (status, attempt) => {
    console.log(`Attempt ${attempt}: ${status.status}`);
  },
});

console.log('Video URL:', result.videoUrl);

// Clean up persistent resources when done
await client.close();
```
