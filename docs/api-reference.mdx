# API Reference

Complete reference for all exports from `@getvrex/glabs-sdk`.

## Classes

### GLabsClient

Main SDK client. See [Client Configuration](/docs/glabs-sdk/client).

```typescript
import { GLabsClient } from '@getvrex/glabs-sdk';

const client = new GLabsClient(config: GLabsClientConfig);
```

**Properties:**
- `accountTier: AccountTier` — configured account tier
- `projectId: string | undefined` — configured project ID

**Methods:**
- `refreshToken(): Promise<void>` — manual token refresh
- `close(): Promise<void>` — close persistent resources

**Static Methods:**
- `GLabsClient.generateSessionId(): string` — generate session ID

**Namespaces:**
- `client.projects` — project management
- `client.images` — image generation
- `client.videos` — video generation

### OpenAIServer

OpenAI-compatible HTTP server. See [OpenAI Server](/docs/glabs-sdk/openai-server).

```typescript
import { OpenAIServer } from '@getvrex/glabs-sdk/openai';

const server = new OpenAIServer(client: GLabsClient, config?: OpenAIServerConfig);
await server.start();
await server.stop();
```

## client.projects

| Method | Returns | Description |
|--------|---------|-------------|
| `list(options?)` | `Promise<ListProjectsResult>` | List projects with pagination |
| `get(options)` | `Promise<GetProjectResult>` | Get project by ID |
| `getFirstProjectId()` | `Promise<string>` | Get first project (cached) |
| `clearCache()` | `void` | Clear project cache |

## client.images

| Method | Returns | Description |
|--------|---------|-------------|
| `generate(options)` | `Promise<GenerateImageResult>` | Generate images from prompt |
| `upload(options)` | `Promise<UploadImageResult>` | Upload image for video gen |
| `upsampleImage(options)` | `Promise<UpsampleImageResult>` | Upscale image to 2K/4K |
| `getCreditStatus()` | `Promise<CreditStatusResult>` | Check account credits |

## client.videos

| Method | Returns | Description |
|--------|---------|-------------|
| `generateTextToVideo(options)` | `Promise<VideoOperationResult>` | Text-to-video generation |
| `generateImageToVideo(options)` | `Promise<VideoOperationResult>` | Image-to-video (start/end frame) |
| `generateReferenceImagesVideo(options)` | `Promise<VideoOperationResult>` | Reference images video |
| `extend(options)` | `Promise<VideoOperationResult>` | Extend existing video |
| `reshoot(options)` | `Promise<VideoOperationResult>` | Camera control reshoot |
| `upsample(options)` | `Promise<VideoOperationResult>` | Upscale to HD/4K |
| `checkStatus(options)` | `Promise<VideoStatusResult>` | Check generation status |
| `pollOperation(options)` | `Promise<VideoStatusResult>` | Poll until completion |

## Tier Configuration Functions

```typescript
import {
  getTierCapabilities,
  getEffectiveVideoMode,
  getPaygateTier,
  getVideoAspectRatioEnum,
  getImageAspectRatioEnum,
  getVideoModelKey,
  getVideoApiConfig,
  getImageApiConfig,
  isFeatureSupported,
} from '@getvrex/glabs-sdk';
```

| Function | Returns | Description |
|----------|---------|-------------|
| `getTierCapabilities(tier)` | `TierCapabilities` | Get tier capabilities |
| `getEffectiveVideoMode(tier, mode?)` | `VideoMode` | Get effective video mode |
| `getPaygateTier(tier)` | `PaygateTier` | Get paygate tier enum |
| `getVideoAspectRatioEnum(ratio)` | `VideoAspectRatioEnum` | Video aspect ratio enum |
| `getImageAspectRatioEnum(ratio)` | `ImageAspectRatioEnum` | Image aspect ratio enum |
| `getVideoModelKey(type, tier, ratio, mode?)` | `string` | Video model key |
| `getVideoApiConfig(type, tier, ratio, mode?)` | `VideoApiConfig` | Full video API config |
| `getImageApiConfig(tier, ratio, model?)` | `ImageApiConfig` | Full image API config |
| `isFeatureSupported(feature, tier, ratio?)` | `FeatureSupportResult` | Check feature support |
