# Video Generation

Generate AI videos using Google's Veo 3.1 models via `client.videos`.

## Text-to-Video

Generate a video from a text prompt:

```typescript
const operation = await client.videos.generateTextToVideo({
  prompt: 'A cinematic drone shot over a tropical coastline at golden hour',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
  videoMode: 'quality',  // optional: 'quality' | 'fast'
});

console.log('Operation:', operation.operationName);
console.log('Scene ID:', operation.sceneId);
console.log('Credits remaining:', operation.remainingCredits);
```

### Options

```typescript
type GenerateTextToVideoOptions = {
  prompt: string;              // Required: video description
  sessionId: string;           // Required: session ID
  aspectRatio: AspectRatio;    // Required: '16:9' | '9:16' | '1:1'
  projectId?: string;          // Auto-resolved if omitted
  accountTier?: AccountTier;   // Override client tier for this request
  videoMode?: VideoMode;       // 'quality' | 'fast' (default: tier-dependent)
  seed?: number;               // Random seed for reproducibility
  sceneId?: string;            // Scene ID for tracking
};
```

## Image-to-Video

Generate a video from a start frame image, optionally with an end frame:

```typescript
// Upload an image first
const upload = await client.images.upload({
  imageBase64: myImageBase64,
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});

// Start frame only (I2V)
const operation = await client.videos.generateImageToVideo({
  prompt: 'Camera slowly zooms into the scene',
  startMediaId: upload.mediaId!,
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});

// First + Last frame (I2V-FL)
const operationFL = await client.videos.generateImageToVideo({
  prompt: 'Smooth transition between scenes',
  startMediaId: startUpload.mediaId!,
  endMediaId: endUpload.mediaId!,  // triggers FL mode
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});
```

### Options

```typescript
type GenerateImageToVideoOptions = {
  prompt: string;              // Required: video description
  startMediaId: string;        // Required: first frame image media ID
  sessionId: string;           // Required
  aspectRatio: AspectRatio;    // Required
  endMediaId?: string;         // Last frame image (triggers FL mode)
  projectId?: string;          // Auto-resolved
  accountTier?: AccountTier;   // Override client tier
  videoMode?: VideoMode;       // 'quality' | 'fast'
  seed?: number;
  sceneId?: string;
  cropCoordinates?: {          // Crop the start image
    top?: number;
    left?: number;
    bottom?: number;
    right?: number;
  };
};
```

## Reshoot (Camera Control)

Apply camera motion controls to an existing video:

```typescript
const operation = await client.videos.reshoot({
  mediaId: 'existing-video-media-id',
  reshootMotionType: 'RESHOOT_MOTION_TYPE_DOLLY_IN_ZOOM_OUT',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});
```

### Motion Types

**Camera Movement:**
| Type | Description |
|------|-------------|
| `RESHOOT_MOTION_TYPE_UP` | Pan up |
| `RESHOOT_MOTION_TYPE_DOWN` | Pan down |
| `RESHOOT_MOTION_TYPE_LEFT_TO_RIGHT` | Pan left to right |
| `RESHOOT_MOTION_TYPE_RIGHT_TO_LEFT` | Pan right to left |
| `RESHOOT_MOTION_TYPE_FORWARD` | Move forward |
| `RESHOOT_MOTION_TYPE_BACKWARD` | Move backward |
| `RESHOOT_MOTION_TYPE_DOLLY_IN_ZOOM_OUT` | Dolly in + zoom out |
| `RESHOOT_MOTION_TYPE_DOLLY_OUT_ZOOM_IN_LARGE` | Dolly out + zoom in |

**Camera Position (stationary movement):**
| Type | Description |
|------|-------------|
| `RESHOOT_MOTION_TYPE_STATIONARY_UP` | Tilt up |
| `RESHOOT_MOTION_TYPE_STATIONARY_DOWN` | Tilt down |
| `RESHOOT_MOTION_TYPE_STATIONARY_LEFT_LARGE` | Pan left |
| `RESHOOT_MOTION_TYPE_STATIONARY_RIGHT_LARGE` | Pan right |
| `RESHOOT_MOTION_TYPE_STATIONARY_DOLLY_IN_ZOOM_OUT` | Stationary dolly in |
| `RESHOOT_MOTION_TYPE_STATIONARY_DOLLY_OUT_ZOOM_IN_LARGE` | Stationary dolly out |

## Upsample (Upscale) Video


### Options

### Status Values

| Status | Description |
|--------|-------------|
| `MEDIA_GENERATION_STATUS_PENDING` | Queued |
| `MEDIA_GENERATION_STATUS_ACTIVE` | Processing started |
| `MEDIA_GENERATION_STATUS_PROCESSING` | Actively generating |

| `MEDIA_GENERATION_STATUS_FAILED` | Generation failed |

## Poll Operation

Poll a video operation until completion with progress callbacks:

```typescript
const result = await client.videos.pollOperation({
  operationName: operation.operationName,
  maxAttempts: 60,       // default: 60
  intervalMs: 10000,     // default: 10000 (10s)
  onProgress: (status, attempt) => {
    console.log(`[${attempt}/60] ${status.status}`);
  },
});

if (result.videoUrl) {
  console.log('Video URL:', result.videoUrl);
} else if (result.error) {
  console.error('Failed:', result.error);
}
```

### Options

```typescript
type PollOperationOptions = {
  operationName?: string;      // Operation name
  sceneId?: string;            // Scene ID
  mediaId?: string;            // Media ID (new format)
  projectId?: string;          // Project ID (new format)
  maxAttempts?: number;        // Max polls (default: 60)
  intervalMs?: number;         // Interval between polls in ms (default: 10000)
  onProgress?: (status: VideoStatusResult, attempt: number) => void;
};
```

### Result

```typescript
type VideoStatusResult = {
  status: string;              // Generation status
  videoUrl?: string;           // URL to generated video
  thumbnailUrl?: string;       // Thumbnail URL
  duration?: number;           // Duration in seconds
  mediaGenerationId?: string;  // Generation ID
  error?: string;              // Error message if failed
  remainingCredits?: number;   // Credits remaining
};
```

## Operation Result

All generation methods return a `VideoOperationResult`:

```typescript
type VideoOperationResult = {
  operationName: string;       // For status polling
  sceneId: string;             // Scene identifier
  mediaId?: string;            // Media ID
  status: string;              // Initial status
  remainingCredits?: number;   // Credits after operation
};
```

## Video Modes

| Mode | Description | Default For |
|------|-------------|-------------|
| `quality` | Higher quality, slower | Ultra tier |
| `fast` | Faster generation | Pro tier |

The mode is automatically selected based on your account tier, but can be overridden per-request:

```typescript
// Force quality mode on Pro tier
const operation = await client.videos.generateTextToVideo({
  prompt: 'A slow-motion waterfall',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
  videoMode: 'quality',
});
```

## Complete Example: Image-to-Video Pipeline

```typescript
import { GLabsClient } from '@getvrex/glabs-sdk';
import { readFileSync } from 'fs';

const client = new GLabsClient({
  bearerToken: process.env.GLABS_BEARER_TOKEN!,
  sessionToken: process.env.GLABS_SESSION_TOKEN,
  accountTier: 'pro',
  recaptcha: { provider: 'regotcha', apiKey: process.env.RECAPTCHA_API_KEY! },
});

// 1. Upload image
const imageData = readFileSync('scene.jpg').toString('base64');
const upload = await client.images.upload({
  imageBase64: imageData,
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});

// 2. Generate video from image
const operation = await client.videos.generateImageToVideo({
  prompt: 'Camera slowly reveals the full landscape with gentle wind',
  startMediaId: upload.mediaId!,
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});

// 3. Poll until done
const result = await client.videos.pollOperation({
  operationName: operation.operationName,
  onProgress: (s, n) => console.log(`[${n}] ${s.status}`),
});

// 4. Extend the video
if (result.mediaGenerationId) {
  const extendOp = await client.videos.extend({
    mediaId: result.mediaGenerationId,
    prompt: 'Continue with a dramatic sunset reveal',
    sessionId: GLabsClient.generateSessionId(),
    aspectRatio: '16:9',
  });

  const extendResult = await client.videos.pollOperation({
    operationName: extendOp.operationName,
  });

  console.log('Extended video:', extendResult.videoUrl);
}

await client.close();
```
