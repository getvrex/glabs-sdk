# Getting Started

## Installation

```bash
npm install @getvrex/glabs-sdk
```

**Note:** This is a private package hosted on GitHub Packages. Configure your `.npmrc`:

```
@getvrex:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_TOKEN}
```

### Optional Peer Dependencies

For browser-based reCAPTCHA providers:

```bash
# For the "playwright" reCAPTCHA provider
npm install playwright

# The "chrome" provider uses chrome-remote-interface (bundled)
```

## Prerequisites

1. **Bearer Token** — Authentication token from Google Labs (obtained from API requests or via session token refresh)
2. **Session Token** (recommended) — `__Secure-next-auth.session-token` cookie value from `labs.google` — enables auto token refresh
3. **reCAPTCHA Provider** — Required for all image and video generation
4. **Project ID** (optional) — Auto-resolved from your account if not provided

## Basic Setup

```typescript
import { GLabsClient } from '@getvrex/glabs-sdk';

const client = new GLabsClient({
  bearerToken: process.env.GLABS_BEARER_TOKEN!,
  sessionToken: process.env.GLABS_SESSION_TOKEN,
  accountTier: 'pro',
  recaptcha: {
    provider: 'regotcha',
    apiKey: process.env.RECAPTCHA_API_KEY!,
  },
});
```

## Environment Variables

```bash
# .env
GLABS_BEARER_TOKEN=your-bearer-token
GLABS_SESSION_TOKEN=your-session-token
GLABS_PROJECT_ID=your-project-id
RECAPTCHA_PROVIDER=regotcha
RECAPTCHA_API_KEY=your-recaptcha-api-key
```

```typescript
import { GLabsClient } from '@getvrex/glabs-sdk';

const client = new GLabsClient({
  bearerToken: process.env.GLABS_BEARER_TOKEN!,
  sessionToken: process.env.GLABS_SESSION_TOKEN,
  projectId: process.env.GLABS_PROJECT_ID,
  recaptcha: {
    provider: process.env.RECAPTCHA_PROVIDER as 'regotcha' | 'capsolver',
    apiKey: process.env.RECAPTCHA_API_KEY!,
  },
});
```

## Session IDs

Every API request requires a session ID. Generate one using the static method:

```typescript
const sessionId = GLabsClient.generateSessionId();
// Returns: ";1709123456789" (Google's expected format)
```

## First Image

```typescript
const result = await client.images.generate({
  prompt: 'A serene mountain lake at dawn',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});

// result.images[0].encodedImage — base64 PNG
// result.images[0].fifeUrl — Google CDN URL
```

## First Video

```typescript
// Start generation
const operation = await client.videos.generateTextToVideo({
  prompt: 'A cinematic drone shot over a coastline',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});

// Poll until done
const result = await client.videos.pollOperation({
  operationName: operation.operationName,
  onProgress: (status, attempt) => {
    console.log(`[${attempt}] ${status.status}`);
  },
});

if (result.videoUrl) {
  console.log('Video ready:', result.videoUrl);
}
```

## Cleanup

If using browser-based reCAPTCHA providers (Playwright or Chrome), close the client when done:

```typescript
await client.close();
```

## Error Handling

```typescript
import { GLabsError } from '@getvrex/glabs-sdk';

try {
  await client.images.generate({ ... });
} catch (error) {
  if (error instanceof GLabsError) {
    console.error(`[${error.code}] ${error.message}`);
    console.error('HTTP Status:', error.statusCode);
  }
}
```
