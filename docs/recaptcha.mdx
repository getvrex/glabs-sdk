# reCAPTCHA Configuration

All image and video generation requires reCAPTCHA verification. The SDK supports 7 providers with automatic retry and fallback chains.

**Recommended providers:**
- **Chrome** (default) — Real Chrome browser, persistent context, highest success rate
- **YesCaptcha** — Reliable cloud-based solving service

**Other providers:**
- Playwright, Regotcha, CapSolver, Veo3Solver, Custom (self-hosted)

## Why reCAPTCHA?

Google Labs uses reCAPTCHA v3 Enterprise to protect against abuse. The SDK handles this transparently:

1. All generation requests require a reCAPTCHA token
2. SDK automatically fetches a token before each request
3. If token evaluation fails, SDK retries with a new token (up to 20 attempts)

## Supported Providers

### Chrome (Recommended)

Uses a real Chrome browser with persistent context via Chrome DevTools Protocol. Achieves the highest reCAPTCHA scores by maintaining a real browser session.

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  recaptcha: {
    provider: 'chrome',
    chromeOptions: {
      headless: false,     // headed mode = higher scores (default: false)
      projectId: 'your-project-id', // for page URL context
      maxRetries: 3,       // retries per token request (default: 3)
      timeout: 30000,      // page/script timeout ms (default: 30000)
      userDataDir: '~/.glabs-sdk/chrome-profile', // persistent profile path
      proxy: {             // optional proxy
        server: 'http://proxy:8080',
        username: 'user',
        password: 'pass',
      },
    },
  },
});
```

**Why Chrome?**
- Persistent browser context — maintains cookies and session across requests
- Real Chrome fingerprint — highest reCAPTCHA v3 scores
- No external API dependency — runs locally
- Auto-cleanup via `client.close()`

### YesCaptcha (Recommended)

[YesCaptcha](https://yescaptcha.com) is a reliable cloud-based captcha solving service.

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  recaptcha: {
    provider: 'yescaptcha',
    apiKey: 'your-yescaptcha-client-key',
    maxRetries: 20, // max polling attempts (default: 20)
  },
});
```

**Why YesCaptcha?**
- No local browser required
- Consistent success rates
- Simple setup

### Playwright

Uses a Playwright-managed browser to generate reCAPTCHA tokens locally.

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  recaptcha: {
    provider: 'playwright',
    playwrightOptions: {
      headless: false,     // headed = higher scores (default: false)
      projectId: 'your-project-id',
      maxRetries: 3,
      timeout: 30000,
      proxy: {
        server: 'http://proxy:8080',
        username: 'user',
        password: 'pass',
      },
    },
  },
});
```

**Note:** Requires `playwright` as a peer dependency: `npm install playwright`

### Regotcha

[Regotcha](https://regotcha.com) is optimized for Google Labs reCAPTCHA v3 Enterprise.

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  recaptcha: {
    provider: 'regotcha',
    apiKey: 'your-regotcha-api-key',
    maxRetries: 30,
  },
});
```

### CapSolver

[CapSolver](https://capsolver.com) provides proxy support and browser fingerprinting.

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  recaptcha: {
    provider: 'capsolver',
    apiKey: 'your-capsolver-api-key',
    proxy: 'http://user:pass@ip:port', // optional residential proxy
    maxRetries: 30,
  },
});
```

CapSolver returns additional browser fingerprint data (`userAgent`, `secChUa`) that the SDK automatically includes in requests.

### Veo3Solver

Token service that provides pre-solved reCAPTCHA tokens via JWT authentication.

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  recaptcha: {
    provider: 'veo3solver',
    jwtToken: 'your-jwt-token',
  },
});
```

No polling required — tokens are returned immediately.

### Custom Solver

Use your own self-hosted reCAPTCHA solver service.

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  recaptcha: {
    provider: 'custom',
    customEndpoint: 'http://localhost:8000/solve',
    proxy: 'http://user:pass@host:port',
    anchor: 'base64-encoded-anchor',
    reload: 'base64-encoded-reload',
  },
});
```

**Custom Solver API:**

Request (POST):
```json
{
  "websiteURL": "https://labs.google",
  "websiteKey": "6LdsFiUsAAAAAIjVDZcuLhaHiDn5nnHVXVRQGeMV",
  "pageAction": "IMAGE_GENERATION",
  "anchor": "...",
  "reload": "...",
  "proxy": "http://user:pass@host:port"
}
```

Response:
```json
{ "success": true, "token": "03AFcWeA..." }
```

### Static Token (Testing)

Bypass all provider logic with a pre-obtained token:

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  recaptcha: {
    provider: 'chrome',  // required but ignored
    staticToken: 'your-pre-obtained-token',
  },
});
```

## Fallback Chains

Configure a fallback provider when the primary fails:

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  recaptcha: {
    provider: 'chrome',
    chromeOptions: { headless: false },
    fallback: {
      provider: 'yescaptcha',
      apiKey: 'your-yescaptcha-key',
      fallback: {
        provider: 'regotcha',
        apiKey: 'your-regotcha-key',
      },
    },
  },
});
```

When Chrome fails to produce a token, the SDK automatically tries YesCaptcha, then Regotcha.

## Configuration Reference

| Option | Type | Required | Description |
|--------|------|----------|-------------|
| `provider` | `RecaptchaProvider` | Yes | Provider to use |
| `apiKey` | `string` | Yes* | API key (*not required for custom/veo3solver/chrome/playwright) |
| `jwtToken` | `string` | No** | JWT token (**required for veo3solver) |
| `customEndpoint` | `string` | No*** | Solver URL (***required for custom) |
| `staticToken` | `string` | No | Static token (bypasses provider) |
| `proxy` | `string` | No | Proxy URL (CapSolver and Custom) |
| `anchor` | `string` | No | Anchor parameter (Custom only) |
| `reload` | `string` | No | Reload parameter (Custom only) |
| `maxRetries` | `number` | No | Max polling attempts |
| `pageAction` | `string` | No | Override reCAPTCHA page action |
| `playwrightOptions` | `object` | No | Playwright browser config |
| `chromeOptions` | `object` | No | Chrome browser config |
| `fallback` | `RecaptchaConfig` | No | Fallback provider config |

### RecaptchaProvider Values

```typescript
type RecaptchaProvider =
  | 'chrome'       // Real Chrome browser (persistent)
  | 'playwright'   // Playwright browser
  | 'yescaptcha'   // YesCaptcha cloud service
  | 'regotcha'     // Regotcha cloud service
  | 'capsolver'    // CapSolver cloud service
  | 'veo3solver'   // Veo3Solver token service
  | 'custom';      // Self-hosted solver
```

## How It Works

### Cloud Provider Flow (YesCaptcha, CapSolver, Regotcha)

```
SDK → Provider: createTask (ReCaptchaV3Enterprise)
Provider → SDK: taskId
SDK → Provider: getTaskResult (polling every 2-5s)
Provider → SDK: { token: "03AFcWeA..." }
```

### Browser Provider Flow (Chrome, Playwright)

```
SDK: Navigate to labs.google in browser
SDK: Execute grecaptcha.enterprise.execute()
SDK: Extract reCAPTCHA token from page
SDK → API: Include token in request
```

### Automatic Retry on Evaluation Failure

When Google rejects a token with "reCAPTCHA evaluation failed":

1. SDK detects the 403 evaluation failure
2. Requests a new token from provider
3. Retries the API request (up to 20 attempts)

```
[Image] reCAPTCHA token obtained, generating...
[Image] reCAPTCHA evaluation failed (attempt 1/20), retrying...
[Image] reCAPTCHA token obtained, generating...
✓ Success
```

## Without reCAPTCHA

Without reCAPTCHA configuration, generation requests will fail:

```typescript
const client = new GLabsClient({
  bearerToken: 'your-token',
  // No recaptcha config
});

await client.images.generate({...});
// Error: reCAPTCHA configuration is required for image generation
```

## Cleanup

Browser-based providers (Chrome, Playwright) maintain persistent browser instances. Always close the client when done:

```typescript
await client.close();
```
