# Image Generation

Generate AI images using Google's Imagen 4 models via `client.images`.

## Generate Images

```typescript
const result = await client.images.generate({
  prompt: 'A photorealistic portrait of a robot painter',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});

for (const image of result.images) {
  console.log('Base64:', image.encodedImage?.slice(0, 50) + '...');
  console.log('CDN URL:', image.fifeUrl);
  console.log('Media ID:', image.mediaId);
}
```

### Options

```typescript
type GenerateImageOptions = {
  prompt: string;              // Required: text prompt
  sessionId: string;           // Required: session ID
  aspectRatio: AspectRatio;    // Required: '16:9' | '9:16' | '1:1'
  projectId?: string;          // Auto-resolved if omitted
  model?: ImageModel;          // 'nanobanana' | 'nanobananapro' | 'imagen-4' | 'imagen-4-fast' | 'imagen-4-ultra'
  count?: number;              // Images to generate (1-4, default: 1)
  references?: ImageReference[]; // Reference images for style guidance
  seed?: number;               // Random seed for reproducibility
  prompts?: string[];          // Multiple different prompts (overrides count)
};
```

### Result

```typescript
type GenerateImageResult = {
  images: GeneratedImage[];
  sessionId: string;
};

type GeneratedImage = {
  encodedImage?: string;       // Base64-encoded PNG
  mediaId?: string;            // Media ID (use for video generation)
  mediaGenerationId?: string;  // Generation tracking ID
  workflowId?: string;         // Workflow tracking ID
  prompt?: string;             // Prompt used for this image
  seed?: number;               // Seed used
  mimeType?: string;           // Image MIME type
  fifeUrl?: string;            // Google CDN URL
};
```

### Batch Generation

Generate multiple images in one request:

```typescript
// Same prompt, multiple images
const result = await client.images.generate({
  prompt: 'A futuristic cityscape',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
  count: 4,  // up to 4
});

// Different prompts per image
const result = await client.images.generate({
  prompt: 'base prompt',  // required but overridden by prompts[]
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '1:1',
  prompts: [
    'A red sports car',
    'A blue sports car',
    'A green sports car',
  ],
});
```

### Image Models

| Model | Internal Name | Description |
|-------|--------------|-------------|
| `nanobanana` | `GEM_PIX` | Imagen 4 standard |
| `nanobananapro` | `GEM_PIX_2` | Imagen 4 Pro |
| `imagen-4` | `GEM_PIX` | Alias for nanobanana |
| `imagen-4-fast` | `GEM_PIX` | Fast variant |
| `imagen-4-ultra` | `GEM_PIX` | Ultra variant |

### Reference Images

Use previously generated or uploaded images as style references:

```typescript
const result = await client.images.generate({
  prompt: 'Same style but with a mountain background',
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
  references: [
    { mediaId: 'previously-generated-media-id' },
    { mediaGenerationId: 'another-generation-id' },
  ],
});
```

## Upload Images

Upload a base64-encoded image for use in image-to-video generation:

```typescript
import { readFileSync } from 'fs';

const imageBase64 = readFileSync('photo.jpg').toString('base64');

const upload = await client.images.upload({
  imageBase64,
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
  fileName: 'photo.jpg',
});

console.log('Media ID:', upload.mediaId);
console.log('Media Gen ID:', upload.mediaGenerationId);

// Use the mediaId for image-to-video generation
await client.videos.generateImageToVideo({
  prompt: 'Camera slowly pans across the scene',
  startMediaId: upload.mediaId!,
  sessionId: GLabsClient.generateSessionId(),
  aspectRatio: '16:9',
});
```

### Upload Options

```typescript
type UploadImageOptions = {
  imageBase64: string;     // Base64 data (with or without data URL prefix)
  sessionId: string;       // Session ID
  aspectRatio?: AspectRatio; // Aspect ratio hint
  projectId?: string;      // Project ID
  fileName?: string;       // File name
  mimeType?: string;       // MIME type (auto-detected from data URL)
};
```

### Upload Result

```typescript
type UploadImageResult = {
  mediaGenerationId?: string;
  mediaId?: string;
  width?: number;
  height?: number;
  workflowId?: string;
  sessionId: string;
};
```

## Upsample Images

Upscale an image to 2K or 4K resolution:

```typescript
const upsampled = await client.images.upsampleImage({
  mediaId: 'generated-image-media-id',
  targetResolution: 'UPSAMPLE_IMAGE_RESOLUTION_4K',
});

console.log('Upsampled base64:', upsampled.encodedImage.slice(0, 50) + '...');
```

### Upsample Options

```typescript
type UpsampleImageOptions = {
  mediaId: string;           // Media ID of the image to upsample
  targetResolution?: 'UPSAMPLE_IMAGE_RESOLUTION_2K' | 'UPSAMPLE_IMAGE_RESOLUTION_4K';
  projectId?: string;
  sessionId?: string;
};
```

## Aspect Ratios

All image generation supports three aspect ratios:

| Ratio | Orientation | Use Case |
|-------|-------------|----------|
| `16:9` | Landscape | Desktop wallpapers, videos |
| `9:16` | Portrait | Mobile wallpapers, stories |
| `1:1` | Square | Social media, avatars |
